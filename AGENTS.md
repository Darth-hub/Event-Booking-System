# Project collaboration instructions

This is a guided movie-ticket booking project. Read `outputs/project-log.md` before continuing project work; it records the user's roadmap, confirmed decisions, open questions, and learning progress.

Follow phases 0–9 in that log. Discuss design decisions before writing application code. End each phase with a checkpoint grill and record the user's actual understanding and unresolved gaps. Do not skip ahead to generating the application.

Update `outputs/project-log.md` when requirements or decisions change, a substantive learning session finishes, a checkpoint is attempted, or an experiment produces results. Keep proposed assumptions separate from agreed choices and measured results. Preserve decision history when revising a choice.

The initial target is 1,000–2,000 total users, not simultaneous requests. Capacity remains unmeasured. Learning and defensible interview explanations are central deliverables.
