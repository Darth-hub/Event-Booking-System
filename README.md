# Event Booking System

A guided movie-ticket booking project focused on seat reservations, concurrency, and reliable booking workflows.

Repository: [Darth-hub/Event-Booking-System](https://github.com/Darth-hub/Event-Booking-System). The repository uses the broader event-booking name; the initial scope is movie shows with reserved seats.

## Status

Phase 0: requirements and capacity estimation. Application implementation has not started.

The initial audience is 1,000–2,000 total users, not simultaneous requests. Workload assumptions and capacity targets are still to be agreed and tested.

## Proposed experience

Browse shows, select seats, temporarily reserve them, and confirm a booking. Simulated payment is proposed for the first version; scope is not yet finalized.

## Working process

Requirements → HLD → data model → APIs → core booking flow → LLD → implementation → testing → scaling → interview preparation.

Every phase ends with a checkpoint discussion. Design decisions and learning happen throughout development.

See the [project and learning log](outputs/project-log.md) for the full roadmap, decisions, open questions, and progress. Candidate technologies are React, Node.js, Express, and PostgreSQL; stack decisions belong to the HLD phase.
